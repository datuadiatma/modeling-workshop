# Introduction

Week 1 provides an overview of how to install Python on your local system, and introduces the basics of geochemical box modeling.

The main paper reference for this week's session is [Kump and Arthur (1999)](../../_assets/KumpArthur1999.pdf). This is a classic paper on carbon isotopes and the modeling of the carbon cycle in deep time. We will go over the elements and processes described in the carbon cycle model, and derrive the equations presented in this paper.

:::{tip} Learning Objectives
After this session, you should be able to:
 - Install the Anaconda Python Distribution on your local machine (i.e., laptop)
 - Derive the canonical isotope mass balance equations.

_Optional, if time permits:_
 - Run Python on your local machine.
 - Use Jupyter Notebooks to display and run Python code.
 - Run Python scripts in the terminal.
:::
