# Week 1: Introduction

Week 1 provides an overview on how to install Python on your local system, and introduces the basic of geochemical box modeling.

The main paper reference for this week's session is [Kump and Arthur (1999)](../../_assets/KumpArthur1999.pdf). This is a classic paper on carbon isotope and the modeling of carbon cycle in deep times. We will go over the basic, the elements and processes described in the carbon cycle model, and derrive the equations presented in this paper.

:::{tip} Learning Objectives
After this session, you should be able to
 - Run Python on your local machine
 - Understand how to use Jupyter Notebooks to display and run Python content.
 - Understand how to run python script in the terminal.
 - Derive the canonical isotope mass balance equations.
:::
