# Solving Ordinary Differential Equations in Python
Week 3 provides an overview on how to implement the Forward Euler Method in Python.

This week is session will be broken down into several parts. First, we will review the Excel exercise that we did and discuss the quetions that I posted last week. Specifically, we will review some of the limitations associated with the Euler method.

We will then spend some time to get familiar with Python and various ways to *"run"* python either interactively, through written scripts, and **Jupyter Notebook**.

Lastly, we will go over some basic Python operations which include importing library, `for loops`, creating numpy arrays, and making some simple plots. By the end of the session you should be able to write a simple forward euler ODE solver in Python.  

:::{tip} Learning Objectives
After this session, you should be able to:
 - Run Python on your local machine.
 - Use Jupyter Notebooks to display and run Python code.
 - Write a simple ODE solver program in Python.
:::
